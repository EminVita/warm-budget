# 页面设计稿

打开 `preview.html` 查看首页和设置页，`preview.png` 为双页截图。

## 替换页面文字

所有示例文字、金额和日期集中在 `content.js`。保留字段名，只修改引号中的内容，然后刷新页面即可。字段值按纯文本显示。

## 调整布局

修改 `preview-template.html` 后运行 `python design/build_preview.py`，重新生成 `preview.html` 和可编辑的 drawio 布局稿。颜色和尺寸位于模板顶部的 CSS 中。HTML 是较精细的视觉稿，drawio 为结构布局稿。

页面使用常规功能名称作为占位，不预设品牌名或宣传文案。当前是示例数据，预算、金额和设置均不持久保存；点击未接入的功能会显示预览提示。设置中的提醒状态仅展示样式。

视觉调整记录：背景改为暖白与柔和渐变，预算卡改为暖杏色，每日成本使用浅绿；统一线条图标，缩短辅助文字，增加分组留白。已确认的费用规则保留在根目录 SPEC.md 中。
